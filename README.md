# Founders AI Program — 講座運営サイト

中小企業の経営者向け「AI実装講座（1対1版・全12回×120分＝24時間・隔週）」を運営するための資料一式です。
GitHub Pages で公開していますが、検索エンジンには登録していません（全ページ `noindex` ／ `robots.txt` で `Disallow`）。

**https://yusuke-aoki-bit.github.io/founders-ai-program/**

## サイトのビルド

**HTMLを直接編集しないでください。** `src/*_body.html` が原稿で、`build.py` がナビとメタタグを付けて各ページを生成します。

```
python3 build.py          # src/ から *.html を再生成
```

`build.py` の `PAGES` にページを足すと、**全ページのナビが変わります。**1ページだけ push すると他のページのナビが古いままになるので、必ず全ページを再生成して push してください。

配布物（docx / pdf / pptx / xlsx）のビルドスクリプトは、このリポジトリには入れていません。claude.ai のプロジェクト「AI講師」側で管理しています。

## 講座の基本形

- 1対1・オンライン／全12回 × 120分 ＝ 24時間／隔週（約5.5か月）
- 受講者は **すでにChatGPTを使っている** 中小企業の経営者・役員
- 第6回・第12回は社員同席の「社内お披露目」。**その1週間前に各30分の壁打ちが別枠で要ります**
- 講師の発話は1回あたり合計35分以内（第6回だけ15分以内）
- 演習は55分。ただし第5・8・10回は65分、第11回は75分
- 人材開発支援助成金（事業展開等リスキリング支援コース）の実訓練時間10時間以上を単独で満たす
