# Founders AI Program — 講座運営サイト

中小企業の経営者向け「AI実装講座（1対1版・全12回×120分）」を運営するための資料サイトです。
GitHub Pages で公開していますが、検索エンジンには登録していません（全ページ noindex ／ robots.txt で Disallow）。

## ページ

| ファイル | 内容 | 主な用途 |
|---|---|---|
| `index.html` | 制作物インデックス・設計判断・次にやること | 案件が動き出したら最初に開く |
| `deliverables.html` | 受講成果物イメージ（成果物7点の完成見本） | 提案・募集案内でクライアントに見せる |
| `roadmap.html` | 講師の学習ロードマップ（進捗をブラウザに保存） | 自分用・常時 |
| `forms.html` | Googleフォーム設置手順（コード全文つき） | 案件の準備時 |
| `assets/AI講座フォーム作成.gs` | Apps Script 本体 | Apps Script に貼って `setupAll` を実行 |

## 講座の基本形

- 1対1・オンライン／全12回 × 120分 ＝ 24時間／隔週
- 受講者は **すでにChatGPTを使っている** 中小企業の経営者・役員
- 第6回・第12回は社員同席の「社内お披露目」
- 人材開発支援助成金（事業展開等リスキリング支援コース）の実訓練時間10時間以上を単独で満たす

## 更新のしかた

このリポジトリのHTMLを直接編集して push すれば、そのまま公開に反映されます。
掲載している事例・数値は現時点ではすべて「目標水準」であり、実績値ではありません。
第1期の実測値が出たら差し替えてください。

制度・料金・機能名の記載は2026年9月時点のものです。案件の開始前に必ず再確認してください。
