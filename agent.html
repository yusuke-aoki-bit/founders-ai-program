設計するものは3つだけです。箱、箱のつなぎ方、外側の囲い。

エージェント ＝ 箱

役割を1つ持たせたAIです。「やること」「やらないこと」「使ってよい道具」「どこまで任せるか」を、箱ごとに決めます。

オーケストレーション ＝ つなぎ方

箱を並べる順番と、箱と箱のあいだに置く「関所」（人が確認する場所）です。何をきっかけに動き、どこへ出すかも決めます。

ガードレール ＝ 囲い

全体にかける決まりです。入れてはいけない情報、人の承認が要る操作、止め方、点検。箱がいくつ増えても、この囲いの中で動かします。

スーパーバイザー ＝ 取りまとめ役

箱が増えてきたら、取りまとめ役を1つ置きます。仕事を分けて各ワーカーに渡し、結果を集めて点検します。自分では作業をしません。ワーカーは ChatGPT・Claude Code・Codex のどれでも動かせます。設計ボードの「スーパーバイザーが振り分ける」で切り替えます。

設計の順番は、囲い → 箱を1つ → つなぐです。先に囲いを決めておくと、あとから箱を足しても事故が起きにくくなります。

    03設計書と指示文

    ボードの内容から自動で作っています。設計書は社内での引き継ぎ用、指示文はChatGPTのプロジェクトにそのまま貼る用です。

    設計書

    

    

    
  
    指示文
    
  
    
  
    
  
    選んでいる箱の指示文です。箱を1つにつき、ChatGPTのプロジェクトを1つ作り、その「指示」の欄に貼ります。最後の「動きの記録」が、下の「動きを図にする」の材料になります。
    

    

    
  
    設定ファイル一式（スーパーバイザーとワーカー全員）
    
  
    
  
    Claude Code・Codex で動かすときに置くファイルを、フォルダの形と一緒に並べています。「# ファイル：」の行ごとに分けて保存します。ChatGPT の箱は、その文面をプロジェクトの「指示」に貼ります。
    

    

    
  
    動きを図にする頼み方
    
  
    
  
    箱を流したあと、ふつうのチャットに貼って送ります。最後の「（ここに…）」の所に、各箱が出した「動きの記録」を貼ります。図はコードの枠の「プレビュー」で開きます。
    

    

    
  
    動きを再生できる画面を作らせる頼み方
    
  
    
  
    図の箱が順番に光り、押すとその箱の記録が出る画面を作らせます。正常に流したときと、わざと壊したときの記録を両方貼ると、2つを切り替えて見比べられます。
    

    

    
  
    ChatGPTに、操作できる画面を作らせる頼み方
    
  
    
  
    ふつうのチャットに貼って送ります。ChatGPTがHTMLのコードを書くので、コードの枠の「プレビュー」を押すと、ChatGPTの中で画面が開きます。上の指示文は「箱として働かせる」ためのもの、こちらは「設計の画面そのものを作らせる」ためのものです。

    ChatGPTの中で、画面を作って動かす
    
  
    ChatGPTは、書いたコードをその場で画面として開けます。設計した内容を、ご自身用の操作画面にできます。
    
  
    
    
    手順やること
    
    
      
    1「03」のいちばん下の頼み方をコピーして、ふつうのチャットに貼って送る
    
      
    2回答の中にコードの枠が出る。枠の「プレビュー」を押す
    
      
    3画面が開いたら、箱や関所を押して動くかを確かめる
    
      
    4直したい所は、言葉で頼む（例：「箱の文字を大きく」「関所をもっと目立つ色に」）
    
      
    5残したいときは、コードをコピーして保存するか、共有のリンクを作る
    
        
  
    
  
    プレビューできるのは、HTMLのページ、図（Mermaid・SVG）、グラフなどです。使えるかどうかは、プラン・端末・アカウントの設定で変わります。「プレビュー」が出ないときは、コードをファイルに保存して、ブラウザで開きます。
    

    


    
  
    スーパーバイザーとワーカーを、Codex・Claude Code で動かす
    
  
    設計ボードで「スーパーバイザーが振り分ける」を選ぶと、スーパーバイザーが仕事を分けて、ワーカーに渡し、結果を集めて点検する形になります。ワーカーは1体ずつ、ChatGPT・Claude Code・Codex のどれで動かすかを選べます。
    
  
    
    
    動かす場所スーパーバイザーからの渡し方置くもの
    
    
      
    Claude Codeスーパーバイザー（Claude Code のメインの会話）が、サブエージェントとして呼ぶ.claude/agents/英字の名前.md
    
      
    Codexスーパーバイザーが codex exec のコマンドで起動する。作業フォルダはワーカーごとに分けるworkers/英字の名前/AGENTS.md
    
      
    ChatGPT自動では呼べない。スーパーバイザーが出した依頼票を、人が貼って渡し、結果を貼り返すプロジェクトの「指示」
    
        
  
    
  
    任せる深さは、それぞれの設定にこう置き換えます。
    
  
    
    
    任せる深さClaude Code（サブエージェント）Codex
    
    
      
    読むだけ道具は Read, Grep, Glob（Webで調べるなら WebSearch, WebFetch も）／permissionMode: plan--sandbox read-only
    
      
    下書きまで道具に Write を足す／permissionMode: acceptEdits。書いてよいフォルダを指示で決める--sandbox workspace-write --ask-for-approval never。--cd で作業フォルダを分ける
    
      
    確認してから実行permissionMode: default。人が承認するので、画面を開いた会話で動かす--ask-for-approval on-request。画面を開いた codex で動かす
    
      
    自動で実行permissionMode: acceptEdits ＋ 道具を絞る--sandbox workspace-write --ask-for-approval never
    
      
    使わないbypassPermissions--sandbox danger-full-access／--yolo
    
        
  
    
  
    Claude Code では、メインの会話（スーパーバイザー）が acceptEdits や auto で動いていると、サブエージェントの permissionMode は無視され、メインの設定が使われます。スーパーバイザーは default（毎回確認）で動かします。設定名は2026年10月時点の公式ドキュメントで確かめたものです。版が変わると名前が変わることがあります。
