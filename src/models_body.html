CONCLUSION 1

CONCLUSION 2

差が出るのは価格のほう。

CONCLUSION 3

選定軸は性能ではなく既存環境。

Google Workspace なら Gemini、Microsoft 365 なら Copilot、どちらでもなければ ChatGPT か Claude。これで9割決まります。

用語。これだけ。

初回に配る用語ミニ辞典（A4 1枚）と同じ内容です。説明は経営者の言葉に寄せてあります。講座中に用語を説明する時間を節約するために配ります。

09

この数字を作り直すとき。

3か月ごとに更新します。手順は5つです。

  • 1. 各社公式の価格ページで単価を確認（Anthropic: Claude Platform Docs 価格／OpenAI: 価格改定告知／Google: Gemini API pricing・Cloud Agent Platform pricing）
  • 2. Artificial Analysis で Intelligence Index のバージョン番号を確認してからスコアを取得（バージョンが変わると同一モデルのスコアが動く）
  • 3. 08の年表に新イベントを追記し、02の棒の幅（style="width:NN%"）を更新
  • 4. 05のコスト試算は単価を差し替えれば整合（計算式は棒のラベルに明記してある）
  • 5. ヘッダの「確認日」と「次の更新」を書き換える
更新しないまま3か月を超えたら、受講者に見せないでください。古い数字を配ることは、この講座が一番やってはいけないことです。
